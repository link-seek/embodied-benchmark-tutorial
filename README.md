# 具身智能操作榜单统一教程（v0.1）

9 个机器人操作榜单的统一七段式教程：横向可比、分数带日期出处、版本锁定。给团队新人从零学起、给选型会统一口径用。

## 目录

- `docs/benchmark-tutorial/00-overview.md`：9 榜横向对照表 + 选型三问 + 术语表
- `docs/benchmark-tutorial/01~09`：分榜单七段（定位/规模/引擎本体/观测动作/指标基线/复现路径/局限意义）
- `docs/benchmark-tutorial/99-coverage-report.md`：偏离/遗漏审计报告
- `benchmarks/papers-overview.md` + `benchmarks/papers/*.md`：12 篇论文总览与 Markdown 版（AI 阅读用 md，PDF 见 arXiv 链接）
- `.opencode/skills/benchmark-survey/`：写教程用的定制 survey skill（模板唯一来源）
