## 定位

- RoboDojo 是仿真加真机统一的通用操作评测，核心是按能力维度剖分短板（记忆、精度、长时程等），回答“策略到底卡在哪一类能力上”这类问题，不测单一总榜首排名（来源：论文摘要与第 1 节）。
- 双循环设计：仿真做快速迭代与能力诊断，真机做标准化可复现的部署验证，两套经 XPolicyLab 同一策略接口打通（来源：论文第 1 节贡献段与第 4.3 节）。
- 一句话定位表述参考教程站 RoboDojo 章节（<https://benchmark.linkseek.net.cn/>），事实口径以论文与仓库为准。

## 任务规模

- 仿真 42 个标准任务，12 个泛化任务各含标准加随机两档（25 标准轮加 25 随机轮），共 54 组评估设置；真机 18 个任务（3 构型各 6 个）（来源：论文第 3.1.3 节评估设置段与 Fig.2；仓库 `benchmarks/RoboDojo/task/RoboDojo/` 任务目录）。
- 仿真训练数据 3500 条轨迹（35 个任务目录：34 个训练任务加 1 个 DLC 增广目录），共 1859802 帧约 20.66 小时双臂操作数据，25Hz 记录；真机数据 1800 条轨迹共 1611841 帧约 17.91 小时（来源：论文第 3.1.2 节与第 3.2.2 节）。
- 五维能力划分：泛化 12、记忆 6、长时程 8、精度 8、开放 8，共 42 任务，覆盖 24 种操作技能（来源：论文第 3.1.1 节与 Fig.3）。
- 上报策略 30 余种经 XPolicyLab 接入，榜单页持续更新（来源：论文第 4.3 节与第 5 节榜单冻结说明段）。

## 引擎与本体

- 仿真平台 Isaac Sim 5.1 加 IsaacLab 2.3，仿真栈基于 MagicSim 模块化管理器架构，任务由 YAML 模块化配置实例化（来源：论文第 4.1 节与第 4.1.1 节；仓库 `benchmarks/RoboDojo/env/` 与 `env_cfg/`）。
- 异构并行仿真：多环境在同一向量化接口下步进，各环境独立采样场景（物体类别、几何、干扰数、铰接结构、背景可不同），支持多卡分片（来源：论文第 4.1.3 节与 Fig.6；仓库 README Highlights 节）。
- 仿真本体为 ARX X5 双臂平台（双臂基座间距 0.6 米，来源：论文第 3.1 节）；真机三构型：ARX X5、Piper、Piper X（来源：论文第 3.2 节）。
- 真机平台 RoboDojo-RealEval：1.5 米见方工位（台面 1.2 米见方）、固定臂与相机位姿、LED 线光源、触屏评测界面，支持本地与云端远端评测（来源：论文第 4.2 节与 Fig.7）。

## 观测动作

- 仿真观测：RGB 图像加本体状态，任务按 YAML 配置的随机化范围以确定性种子采样（来源：论文第 4.1.1 节重置采样段；仓库 `benchmarks/RoboDojo/env_cfg/` 相机与场景配置）。
- 真机观测：1 个头顶相机加 2 个腕部相机同步 RGB，加机器人状态与语言标注（来源：论文第 3.2.2 节数据段）。
- 动作空间：双臂末端控制，自动合成轨迹经 cuRobo v2 运动规划执行，难合成任务用 VR 遥操作补采（来源：论文第 4.1.4 节数据采集段）。
- 策略接口：XPolicyLab 统一观测更新、动作预测、策略重置、批量查询接口，一次集成同时跑仿真与真机（来源：论文第 4.3 节；仓库 README Highlights 节 eval-only 声明段）。

## 指标与基线

- 主指标为五维能力成功率：每任务 50 轮（仿真共 2100 轮），同时报告成功率与平均分（部分进度分）；总分按五维平均而非按任务平均，避免任务数多的维度主导（来源：论文第 3.1.3 节与第 5.1 节榜单方法段）。
- 五维能力表（2026-07-03，出处：论文 Table 1 仿真榜单，单元格为平均分/成功率，榜首两名见原表标注）：
  - Hy-Embodied-0.5-VLA：泛化 11.77/8.39%、精度 13.81/8.00%、长时程 25.74/14.92%、记忆 13.37/12.11%、开放 0.65/0.58%，平均 13.07/8.80%。
  - SpatialForcing：泛化 14.12/9.33%、精度 17.33/10.58%、长时程 23.26/14.58%、记忆 5.43/4.11%、开放 1.78/1.58%，平均 12.38/8.04%。
  - pi0.5：泛化 13.37/8.17%、精度 12.40/5.50%、长时程 23.54/14.67%、记忆 5.78/4.56%、开放 1.98/1.67%，平均 11.41/6.91%。
  - X-VLA：泛化 10.48/6.78%、精度 18.32/12.00%、长时程 16.53/9.75%、记忆 4.76/3.56%、开放 0.55/0.50%，平均 10.13/6.52%。
- 基线结论：榜首平均成功率约 8% 至 13%，开放维全线低于 2%（榜首开放成功率仅 0.58%），记忆维除榜首外普遍低于 5%（来源：论文 Table 1 与第 6.1 节分析段）。
- 真机榜单：每任务 10 轮，三人双盲独立打分取平均，成功分加子步骤部分分（来源：论文第 3.2.3 节）；仿真与真机为互补关系而非一一对齐的迁移对（来源：论文第 3.2.1 节任务设计段）。
- 榜单治理：AI MMLab Club 非营利基金会维护，官方发布需三随机种子均值加标准差、隐藏布局校验、XPolicyLab 开源检查点与评测视频（来源：论文第 3.3 节）。

## 局限与对我们的意义

- 局限：榜单刻意做难，分数绝对值低，不宜跨榜单直接比大小；真机 18 任务为紧凑物理套件而非五维全覆盖；仿真与真机任务非对齐对，测不出逐任务 sim-to-real 迁移率（来源：论文第 3.2.1 节任务设计段与第 6 章实验分析段）。
- 版本提示：2026-09-16 到 17 修订单帧观测偏差并同步 Hugging Face 数据，重跑多模型结果基本不变；RGB 字节流通道序与 RoboTwin 对齐，需 XPolicyLab `bb9a0b5` 或更新版本（来源：仓库 README News 节）。
- 对我们的意义：适合作为能力短板剖面仪——先跑仿真五维看记忆与开放两维是否塌陷，再读长时程与精度分维定位失败模式；无真机时 18 个真机任务只读结论不复现；要发榜需预留三种子加隐藏布局校验成本（总览表复现成本记为高）。
