## 定位

- RoboTwin 2.0 是双臂协作的操作基准加数据工厂，核心是度量双臂协作与视觉指令泛化，回答“合成数据能否让策略在杂乱真实场景中稳住”这类问题，不测单臂桌面榜首（来源：2.0 论文摘要与第 1 节）。
- 三位一体：专家数据生成管线（MLLM 代码生成加仿真内反馈）加 50 任务评测基准加 10 万余条预采集轨迹，训练与评测共用同一套域随机协议（来源：2.0 论文摘要与 Fig.2）。
- 一句话定位表述参考教程站 RoboTwin 章节（<https://benchmark.linkseek.net.cn/>），事实口径以论文与仓库为准。

## 任务规模

- 50 个双臂协作评测任务，覆盖抓取、放置、交接、堆叠、开合等协作模式，任务清单见文档站任务页（来源：2.0 论文第 3.2 节与 Fig.8；仓库 `benchmarks/RoboTwin/` 任务配置目录）。
- RoboTwin-OD 物体库：731 个物体实例共 147 类，其中自建 RGB-to-3D 重建 534 个（111 类）、Objaverse 153 个（27 类）、SAPIEN PartNet-Mobility 44 个关节物体（9 类），每物体带语义与操作标注（来源：2.0 论文摘要与第 3.1 节）。
- 预采集轨迹 10 万余条，跨 50 任务与 5 种双臂构型（来源：2.0 论文第 3.2 节；数据集页 <https://huggingface.co/datasets/TianxingChen/RoboTwin2.0>，见论文同节外链）。
- 五轴域随机：杂物、光照、背景、台面高度、语言指令五维结构化随机，其中背景纹理库 11000 张（2 万张生成后人工过滤，来源：2.0 论文第 2.2 节与 Fig.4）。

## 引擎与本体

- 仿真引擎 SAPIEN 3.0，物理与渲染走 SAPIEN 管线，任务代码经仿真内执行验证（来源：2.0 论文第 2.1 节执行与日志段；仓库 `benchmarks/RoboTwin/envs/`）。
- 双臂构型 5 种：Aloha-AgileX、ARX-X5、Piper、Franka、UR5，构型配置文件见仓库 `benchmarks/RoboTwin/env_cfg/`（`aloha_agilex.yml`、`arx_x5.yml`、`franka.yml` 等，来源：2.0 论文第 3.2 节与 Fig.5；仓库 `env_cfg/` 目录）。
- 真机对照平台为 COBOT-Magic 双臂平台，4 真机任务（StackBowls、HandoverBlock、PickBottle、ClickBell）各测 4 种背景加杂物组合（来源：2.0 论文第 4.4 节）。
- 部署栈与 RoboDojo 共用 XPolicyLab：单任务评测、多任务多卡调度、远端策略服务加本地仿真（来源：仓库 README 首屏说明节与 `XPolicyLab/` 子模块）。

## 观测动作

- 观测模态：多视角 RGB-D（含头顶大视野、双腕相机、低位可选相机，30Hz 同步），另提供由深度转点云与 RGB-D 转彩色点云两档观测（来源：1.0 论文第 4 节数据段，仿真与真机同硬件布局；2.0 沿用该观测配置，来源：2.0 论文第 4.5 节评测设置段）。
- 本体感知：双臂关节位姿与末端位姿（含主从臂配置，来源：1.0 论文第 4 节数据段）。
- 动作空间：双臂末端位姿加夹爪开合，代码生成 API 覆盖抓取、放置、交接、开合等技能原语（来源：2.0 论文 Fig.3 代码管线与第 2.1 节输入定义段）。
- 语言指令：每轨迹一条多样化指令，由多模态大语言模型按任务模板与物体外观、部件属性组合采样（来源：2.0 论文第 2.2 节轨迹级语言指令段）。

## 指标与基线

- 主指标为任务成功率加视觉与指令泛化剖面：评测分 Easy（干净）与 Hard（域随机：杂物、光照、纹理、高度变化）两档（来源：2.0 论文第 4.5 节评测设置段）。
- 代码生成成功率：2.0 加多模态反馈达 71.3%（2025-06，出处：2.0 论文 Table 1，R2.0+MMFB 行 ASR 列；Top5-ASR 同行 78.6%），1.0 同配置为 63.9%，2.0 架构改进带来 10.9 个百分点提升（出处：2.0 论文摘要与第 4.1 节结果段）。
- 跨构型数据采集成功率：2.0 管线平均 60.5%，较 1.0 基线平均提升 8.3 个百分点，其中 Piper 提升 22.7 个百分点（2.4% 到 25.1%），Aloha-AgileX 提升 13.7 个百分点（出处：2.0 论文 Table 2）。
- 50 任务榜单剖面：5 策略（ACT、DP、RDT、Pi0、DP3）在 Aloha-AgileX 构型上，Easy 到 Hard 平均掉点 RDT 约 20.8 个百分点、Pi0 约 30.1 个百分点；DP3 少样本 Easy 最好（平均 55.2%）但 Hard 仅 5.0%（出处：2.0 论文 Table 5 子集与平均行）。
- 真机迁移：1000 条域随机合成轨迹加 10 条真实演示的 few-shot 设置平均成功率相对提升 367%，纯合成零样本相对提升 228%（2025-06，出处：2.0 论文摘要与第 4.4 节 Table 4）；单臂瓶装任务 1.2% 到 72%、双臂任务 20% 到 62%（出处：1.0 论文 Table 2 与 Table 3，300 条仿真加 20 条真实设置）。

## 局限与对我们的意义

- 局限：榜单主体为仿真 Easy/Hard 剖面，真机验证仅 4 任务；DP3 在仿真中的点云完美分割红利不可直接外推真机；低自由度平台（Piper）绝对成功率仍低（25.1%），跨构型泛化未闭环（来源：2.0 论文第 4.2 节讨论段与第 4.5 节 DP3 分析段）。
- RoboTwin 1.0 对照：1.0 以生成式数字孪生（单张 2D 图经 Rodin 生成 3D 资产）加空间标注代码生成（功能点、接触点、功能轴、接近轴、横向轴）为核心，15 个任务（来源：1.0 论文第 3 至 4 节）；2.0 相对 1.0 的变化是任务 15 到 50、物体库 731 实例 147 类新建、五轴域随机新建、代码生成 47.4%（1.0 Vanilla）到 71.3%（2.0+MMFB）（来源：2.0 论文 Table 1 与第 5.1 节对照段）。
- 对我们的意义：适合作为双臂模仿与泛化的主基准——先用 50 任务 Easy 档验证双臂管线，再开 Hard 档测域随机鲁棒；合成数据策略按“1000 条域随机加 10 条真实”配比起步；有点云条件时 DP3 可作少样本起点，但真机前必须去掉完美分割假设（总览表复现成本记为中）。
