# 分章七段模板（每篇分章唯一结构）

> 要求：七段标题一字固定，不得改字、增删、调序。每段注明主源与溯源要求。篇首加版本头。

---
版本头：论文版本（arXiv 号 + vN） / 本地仓库 commit（`benchmarks/<仓名>@<短hash>`） / 整理日期（YYYY-MM-DD）
---

## 定位

- 主源：论文第 1 节（引言）或摘要定位句。
- 溯源要求：注明论文章节号；一句话说清该榜单测什么、不测什么。

## 任务规模

- 主源：论文任务/数据章节 + 本地仓库 README 路径。
- 溯源要求：任务数、演示数、场景数分别注明出处；数字以仓库 commit 为准、定义以论文为准。

## 引擎与本体

- 主源：论文仿真/平台章节 + 仓库 `README.md` / 环境配置路径。
- 溯源要求：写明仿真引擎与机器人本体；版本号来自仓库，不臆测。

## 观测动作

- 主源：论文观测/动作空间章节或附录。
- 溯源要求：观测模态与动作空间分条列出，注明论文章节或代码文件路径。

## 指标与基线

- 主源：论文评估/实验章节表格。
- 溯源要求：指标定义注明章节；基线方法与分数列表注明表号；SOTA 分数必须带日期与出处（格式见 `citation.md`）。

## 复现路径

- 主源：本地仓库路径（`benchmarks/<仓名>/` 下 README / docs / scripts）。
- 溯源要求：只给入口指引（仓库路径 + 关键文档链接），不写部署步骤、不写最小可跑命令。

## 局限与对我们的意义

- 主源：论文局限章节 + 本教程总览表横向对比。
- 溯源要求：局限注明论文章节；“对我们的意义”明确写出本榜单适合/不适合我们的哪类任务，不写空话。
