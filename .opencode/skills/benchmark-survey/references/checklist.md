# 完工自检清单

每篇教程发布前逐项勾选，7 项全过才算完工。

- [ ] 七段齐全：七段标题一字不差（定位 / 任务规模 / 引擎与本体 / 观测动作 / 指标与基线 / 复现路径 / 局限与对我们的意义），无增删调序。
- [ ] 链接可点：论文 arXiv 链接与仓库路径链接逐个点开验证，无死链。
- [ ] 分数有日期：所有 SOTA 分数带日期 + 出处，多论文同榜单已注明出自哪一篇。
- [ ] 无部署步骤：复现路径只给入口指引，无安装命令、无最小可跑命令、无容器操作。
- [ ] 无 TODO 占位符：全文扫描 TODO / TBD / 待补充 / 未完成，结果为零。
- [ ] 事实有溯源：每个事实陈述可追溯到论文章节或仓库路径；数字以仓库 commit 为准、定义以论文为准；篇首版本头齐全。
