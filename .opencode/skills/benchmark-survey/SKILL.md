# benchmark-survey Skill

> 具身智能榜单统一教程瘦身版 survey skill。后续 10 篇教程（00-overview + 9 篇分章）的唯一模板来源。

## 触发条件

当用户请求满足以下任一条件时，必须使用本 skill：

- 写具身智能榜单教程 / 榜单综述 / 横向对照文档。
- 新建或修改 `docs/benchmark-tutorial/` 下的任何教程文件。
- 需要输出榜单比较表、SOTA 分数、复现路径、分章七段结构时。

不满足上述条件时不要使用本 skill。

## 方法来源（只写要点，不展开理论）

- Webster & Watson 概念中心法：先定维度（概念矩阵列），再把 9 个榜单按同一口径填行，不按论文逐篇罗列。
- Torraco 综合矩阵：总览表即综合矩阵，一行一榜单，一列一维度，缺口单独标出。
- Keshav 三遍法：第一遍只抓定位与规模，第二遍抓引擎/观测/动作/指标，第三遍抓分数日期与复现路径。

## 六步工作流

### 第一步：定维度

1. 固定比较维度为：定位 / 规模 / 引擎 / 指标 / SOTA+日期 / 复现成本。
2. 不增删维度；若某榜单某维度缺失，填“未公开”并标溯源缺口，不臆测。
3. 输出前先复用 `templates/overview-table.md` 的表头。

### 第二步：填比较表

1. 按 `templates/overview-table.md` 填写 9 行，同口径、一行一榜单。
2. 规模数字以本地仓库 commit 为准，定义以论文为准。
3. 写完后回答选型三问，定位本篇读者该看哪一篇分章。

### 第三步：逐篇七段

1. 每篇分章严格复用 `templates/chapter.md` 的七段标题，一字不差：
   定位 / 任务规模 / 引擎与本体 / 观测动作 / 指标与基线 / 复现路径 / 局限与对我们的意义。
2. 每段注明主源（论文章节或仓库路径），无源不写。
3. 每篇顶部加版本头：论文版本 + 本地仓库 commit + 整理日期。

### 第四步：分数标日期

1. 所有 SOTA 分数必须带日期 + 出处，格式见 `templates/citation.md`。
2. 分数只收录论文表格或官方仓库明确声明的数字，不收录二手转述。
3. 同一榜单多篇论文（如 ManiSkill3、RoboCasa365）需注明分数出自哪一篇。

### 第五步：不确定项警示

1. 以下 3 个 arXiv 号凡出现必须标“待点开确认”：CALVIN 2112.03227、RoboCasa 原版 2406.02523、ManiSkill2 2302.04659。
2. 标记格式见 `templates/citation.md`，不得省略警示标记。
3. 其他不确定事实同样标记，不留无标记的存疑陈述。

### 第六步：交叉校验

1. 对照 `references/checklist.md` 逐项自检，7 项全过才算完工。
2. 三源交叉：论文 md 取数（规模/指标/分数）、本地仓库 README 取版本与路径、教程站长文补 Harness 与清单。
3. 只给复现入口指引，不写部署步骤；全文扫描 TODO / TBD / 待补充，零容忍。

## 文件索引

- `templates/overview-table.md`：总览表头模板 + 选型三问。
- `templates/chapter.md`：分章七段模板 + 主源与溯源要求。
- `templates/citation.md`：引用格式 + “待点开确认”警示标记格式。
- `references/checklist.md`：完工自检清单。
